Notes / decisions
-----------------
- `run_agent` reuses `state.context_budget` when no budget is passed (so REPL
  `/context` keeps live stats across turns); otherwise it builds the provider
  default from `resolve_window(state.provider)`.
- `compact_to_budget` uses `target_tokens` to cap the recent tail (minus the
  pinned prefix and a summary reserve) with `keep_recent_tokens` as the
  preferred tail size.
- When a provider reports no usage, the loop falls back to chars/4 estimates of
  appended messages so compaction can still trigger (no stall, no crash).
- No commit was created; the working tree contains the implementation plus the
  pre-existing `agent.py` comment change.

Round 3 — per-turn reset (remaining blocker fixed)
--------------------------------------------------
Problem: the round-2 seed ran at most once per budget (`if not budget.observed`).
Compaction rewrites only the local `messages` list while the session file stays
append-only, so every later REPL turn reloaded the full history against a stale
post-compaction estimate and skipped compaction before its first request
(reviewer probe: turn 2 first request = 303% of the window, no compaction).

Fix: `ContextBudget.seed()` and the `observed` flag are removed. New
`ContextBudget.reset(tokens)` ASSIGNS `estimated_tokens = max(0, tokens)`; `run_agent`
calls `budget.reset(estimate_messages_tokens(messages))` unconditionally, right after
the history is assembled and before the first request of every run. Assignment (not a
max-floor) is correct because the assembled list is exactly what that request carries,
so it cannot double-count. `observe()` replace semantics and its comment are unchanged.
The method is named `reset` to match the verdict's code snippet (the verdict also
allowed `reset_estimate`; both are assignment semantics).

Tests:
- `tests/test_context.py`: the seed/floor/observed tests are replaced by
  `test_budget_reset_assigns_the_assembled_estimate`,
  `test_budget_reset_never_goes_negative`, and
  `test_budget_observe_zero_usage_resets_to_zero`.
- `tests/test_agent_loop.py::test_shared_budget_recompacts_at_the_start_of_each_turn`:
  one Session + one RuntimeState/ContextBudget across two `run_agent` calls
  (60-message history, window 2000). Asserts `compactions_before_call == [1, 2]`
  (a second compaction fired before turn 2's first request), turn 2's first request
  is smaller than the reloaded history, and `budget.compactions == 2`.
- `CLAUDE.md` wording updated to "re-seeded from the assembled history at the start
  of every run".

Gate after round 3: `just check` green (202 tests; ruff/pyright/ty clean),
`just fmt-check` clean.
